# Operating Systems Projects

A collection of interactive and educational projects demonstrating fundamental **Operating Systems** concepts through practical implementations and visual simulations.

This repository contains mini-projects developed as part of an Operating Systems curriculum, focusing on topics such as **process synchronization, deadlocks, concurrency, compression algorithms, and system-level programming**. Each project combines theoretical concepts with hands-on implementations to make learning more intuitive.

## 1. Dining Philosophers Problem Visualization

An interactive web application that visualizes the classic **Dining Philosophers Problem**, demonstrating synchronization techniques, resource allocation, deadlocks, and deadlock prevention in Operating Systems.

### Highlights

* Interactive circular dining table visualization
* Real-time philosopher state animations
* Thread-based simulation using Python
* Deadlock demonstration mode
* Deadlock prevention using semaphores
* Live statistics dashboard
* REST API-driven frontend updates

### Technologies

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* Python Threading

**Key Operating Systems Concepts**

* Synchronization
* Critical Sections
* Mutex Locks
* Semaphores
* Deadlocks
* Deadlock Prevention
* Concurrent Programming

See the project's dedicated `README.md` for complete documentation and setup instructions.

## 2. Huffman Encoding Web Application

A web-based demonstration of the **Huffman Encoding** algorithm that combines a Python Flask backend with a C implementation of the compression algorithm.

The project showcases how low-level algorithms written in C can be integrated into a modern web application.

### Highlights

* Huffman Encoding implementation in C
* Flask-powered web interface
* Interactive frontend
* Demonstrates data compression concepts
* Simple educational interface

### Technologies

* C
* Python
* Flask
* HTML
* CSS
* JavaScript

**Key Concepts**

* Huffman Trees
* Prefix Codes
* Greedy Algorithms
* Lossless Data Compression
* C and Python Integration

See the project's dedicated `README.md` for detailed setup instructions.
